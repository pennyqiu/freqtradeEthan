## 一、回测基础

### 1.1 什么是回测

回测（Backtesting）就像是给你的策略做"单元测试"，用历史数据模拟真实交易，验证策略的有效性。

**程序员视角理解：**
```python
# 回测的本质
for candle in historical_data:
    # 1. 更新当前价格
    current_price = candle['close']
    
    # 2. 运行策略逻辑
    signal = strategy.analyze(candle)
    
    # 3. 模拟交易
    if signal == 'buy' and can_buy():
        trades.append(buy(current_price))
    elif signal == 'sell' and has_position():
        trades.append(sell(current_price))
    
    # 4. 更新止损、ROI等
    update_exit_conditions()

# 5. 计算统计指标
print_results(trades)
```

### 1.2 基础回测命令

```bash
# 最简单的回测

# 指定时间范围

# 指定交易对

# 详细输出
freqtrade backtesting \

```

### 2.2 关键指标解释

**程序员视角理解：**

| 指标 | 程序员理解 | 金融含义 |
|------|-----------|---------|
| **Total Trades** | 函数调用次数 | 总交易次数 |
| **Win Rate** | 测试通过率 | 盈利交易占比 |
| **Avg Profit %** | 平均返回值 | 平均盈利百分比 |
| **Total Profit %** | 总收益率 | 累计盈利百分比 |
| **Drawdown** | 最大回撤 | 账户从峰值到谷底的最大跌幅 |
| **Sharpe Ratio** | 风险调整后收益 | 收益率 / 波动率 (>1为好) |
| **Avg Duration** | 平均持有时间 | 每笔交易的平均时长 |

**重点关注指标：**

1. **胜率（Win Rate）**
   - 60%+ 为优秀
   - 50%-60% 为良好
   - <50% 需要优化

2. **最大回撤（Max Drawdown）**
   - <10% 为优秀
   - 10%-20% 可接受
   - \>20% 风险较高

3. **盈亏比（Profit Factor）**
   - 总盈利 / 总亏损
   - \>2 为优秀
   - 1.5-2 为良好
   - <1.5 需要优化

4. **夏普比率（Sharpe Ratio）**
   - \>2 为优秀
   - 1-2 为良好
   - <1 收益不足以补偿风险

## 三、参数优化（Hyperopt）

### 3.1 定义可优化参数

```python
from freqtrade.strategy import IStrategy, IntParameter, DecimalParameter, CategoricalParameter

class OptimizableStrategy(IStrategy):
    """
    可优化参数的策略
    """
    
    # ========== 可优化的参数 ==========
    
    # 整数参数：RSI阈值
    buy_rsi = IntParameter(20, 40, default=30, space='buy', optimize=True)
    sell_rsi = IntParameter(60, 80, default=70, space='sell', optimize=True)
    
    # 整数参数：均线周期
    ma_fast_period = IntParameter(5, 20, default=10, space='buy', optimize=True)
    ma_slow_period = IntParameter(30, 100, default=50, space='buy', optimize=True)
    
    # 小数参数：止损比例
    stoploss = DecimalParameter(-0.20, -0.05, default=-0.10, space='sell', optimize=True)
    
    # 分类参数：订单类型
    order_type_buy = CategoricalParameter(
        ['limit', 'market'], 
        default='limit', 
        space='buy',
        optimize=False  # 通常不优化订单类型
    )
    
    # ROI参数（自动优化）
    minimal_roi = {
        "0": 0.10,
        "30": 0.05,
        "60": 0.02,
        "120": 0.01
    }
    
    # ========== 策略实现 ==========
    
    def populate_indicators(self, dataframe, metadata):
        # 使用动态参数
        dataframe['ma_fast'] = ta.SMA(dataframe, timeperiod=self.ma_fast_period.value)
        dataframe['ma_slow'] = ta.SMA(dataframe, timeperiod=self.ma_slow_period.value)
        dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
        return dataframe
    
    def populate_entry_trend(self, dataframe, metadata):
        dataframe.loc[
            (
                (dataframe['rsi'] < self.buy_rsi.value) &  # 使用动态参数
                (dataframe['ma_fast'] > dataframe['ma_slow']) &
                (dataframe['volume'] > 0)
            ),
            'enter_long'
        ] = 1
        return dataframe
    
    def populate_exit_trend(self, dataframe, metadata):
        dataframe.loc[
            (
                (dataframe['rsi'] > self.sell_rsi.value)  # 使用动态参数
            ),
            'exit_long'
        ] = 1
        return dataframe
```

### 3.4 自定义优化目标

创建文件 `user_data/hyperopts/CustomLoss.py`：

```python
from datetime import datetime
from freqtrade.optimize.hyperopt import IHyperOptLoss

class CustomHyperOptLoss(IHyperOptLoss):
    """
    自定义优化目标
    
    目标：最大化盈利，同时最小化回撤和交易次数
    """
    
    @staticmethod
    def hyperopt_loss_function(results, trade_count, min_date, max_date, *args, **kwargs):
        """
        计算优化得分（越小越好）
        
        参数:
            results: DataFrame，包含每笔交易的结果
            trade_count: 交易次数
            min_date: 开始日期
            max_date: 结束日期
        """
        # 提取关键指标
        total_profit = results['profit_abs'].sum()
        avg_profit = results['profit_pct'].mean()
        win_rate = len(results[results['profit_abs'] > 0]) / trade_count if trade_count > 0 else 0
        
        # 计算回撤
        cumulative_profit = results['profit_abs'].cumsum()
        running_max = cumulative_profit.cummax()
        drawdown = (running_max - cumulative_profit).max()
        
        # 计算得分（负值表示好，因为优化器最小化目标）
        # 权重可以根据需要调整
        score = (
            -total_profit * 1.0 +      # 最大化总盈利
            drawdown * 2.0 +            # 最小化回撤（权重更高）
            -win_rate * 10.0 +          # 最大化胜率
            trade_count * 0.01          # 轻微惩罚过多交易
        )
        
        return score
```

使用自定义优化目标：

```bash
freqtrade hyperopt \
    --config config.json \
    --strategy OptimizableStrategy \
    --hyperopt-loss CustomHyperOptLoss \
    --epochs 500
```

## 四、避免过拟合

### 4.1 什么是过拟合

**程序员理解：**
过拟合就像是"记住了训练数据的噪声"，在历史数据上表现完美，但在新数据上失效。

```python
# 过拟合示例
if price == 42135.67 and volume == 123.456:  # 太具体了！
    buy()

# 泛化良好的规则
if rsi < 30 and volume > avg_volume:  # 更通用
    buy()
```

### 4.2 防止过拟合的方法

#### 1. 样本外测试（Out-of-Sample Testing）

```bash
# 将数据分为训练集和测试集
# 训练集：2024-01-01 到 2024-08-31
# 测试集：2024-09-01 到 2024-10-31

# 步骤1：在训练集上优化
freqtrade hyperopt \
    --config config.json \
    --strategy MyStrategy \
    --timerange 20240101-20240831 \
    --epochs 500

# 步骤2：在测试集上验证
freqtrade backtesting \
    --config config.json \
    --strategy MyStrategy \
    --timerange 20240901-20241031
```

#### 2. 交叉验证

```bash
# 将数据分成多个时间段，轮流作为测试集

# 折1：训练集(Q1,Q2,Q3), 测试集(Q4)
freqtrade hyperopt --timerange 20240101-20240930
freqtrade backtesting --timerange 20241001-20241231

# 折2：训练集(Q1,Q2,Q4), 测试集(Q3)
freqtrade hyperopt --timerange 20240101-20240630,20241001-20241231
freqtrade backtesting --timerange 20240701-20240930

# 以此类推...
```

#### 3. 参数稳定性测试

```python
# 测试参数在小范围变化时，结果是否稳定
# 如果buy_rsi=30时盈利15%，buy_rsi=31时亏损5%，说明过拟合了

# 好的策略：参数变化 ±10%，结果相对稳定
# 过拟合策略：参数稍微变化，结果剧烈波动
```

#### 4. 简单优于复杂

```python
# ❌ 过度复杂（容易过拟合）
dataframe.loc[
    (
        (dataframe['rsi'] > 28.5) &
        (dataframe['rsi'] < 31.2) &
        (dataframe['ema_9'] > dataframe['ema_13']) &
        (dataframe['ema_13'] > dataframe['ema_21']) &
        (dataframe['volume'] > dataframe['volume'].shift(1) * 1.27) &
        (dataframe['close'] > dataframe['open'] * 1.003)
        # ... 还有10个条件
    ),
    'enter_long'
] = 1

# ✅ 简洁明了（泛化能力强）
dataframe.loc[
    (
        (dataframe['rsi'] < 30) &
        (dataframe['ema_fast'] > dataframe['ema_slow']) &
        (dataframe['volume'] > dataframe['volume_ma'])
    ),
    'enter_long'
] = 1
```

#### 5. 多市场验证

```bash
# 在不同交易对上测试

# BTC上优化

# 在ETH上验证
freqtrade backtesting --pairs ETH/USDT --timerange 20240901-20241031

```
