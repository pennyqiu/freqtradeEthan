## 🚀 快速开始

### 1. 安装 Freqtrade

```bash
# 克隆仓库
git clone https://github.com/freqtrade/freqtrade.git
cd freqtrade

# 安装（自动创建虚拟环境）
./setup.sh -i

# 激活环境
source .venv/bin/activate  # Linux/Mac
# 或
.venv\Scripts\activate     # Windows
```

### 2. 下载示例数据

```bash
# 下载30天的BTC和ETH数据
freqtrade download-data \
    --exchange binance \
    --pairs BTC/USDT ETH/USDT \
    --timeframe 5m \
    --days 30
```

### 3. 运行第一个回测

```bash
# 复制示例配置
cp config_examples/config_binance.example.json config.json

# 回测示例策略
freqtrade backtesting \
    --config config.json \
    --strategy SampleStrategy \
    --timerange 20240101-20240301
```

### 4. 开始学习

从 [第1章：项目概述与架构](./第1章_项目概述与架构.md) 开始你的学习之旅！

## 💡 学习建议

### 对于初学者：

1. **按顺序学习** - 章节之间有递进关系
2. **动手实践** - 每个示例都要自己运行一遍
3. **不要跳过第1-2章** - 理解架构很重要
4. **慢慢来** - 建议至少花1个月完整学习

### 对于有经验的开发者：

1. 可以快速浏览第1-2章架构部分
2. 重点学习第3-4章（策略开发和回测）

## ⚠️ 重要提醒

### 风险警告

```
┌─────────────────────────────────────────┐
│  ⚠️  量化交易有风险，入市需谨慎！        │
│                                         │
│  • 历史表现不代表未来收益               │
│  • 回测好 ≠ 实盘好                      │
│  • 永远不要投入超过你能承受损失的资金   │
│  • 建议从小资金开始                     │
│  • 充分测试后再扩大规模                 │
└─────────────────────────────────────────┘
```

### 新手建议

1. **先学习，再实盘** - 至少完成前4章
2. **充分回测** - 多个时间段、多个市场环境
3. **模拟盘测试** - 至少运行1-2周
4. **小资金开始** - 100-500 USDT 足够
5. **设置止损** - 永远设置止损
6. **保持记录** - 记录所有决策和结果
