# 第1章：Freqtrade 项目概述与架构

## 一、项目概述（程序员视角）

**Freqtrade 本质上是一个"事件驱动的循环决策系统"**，就像游戏引擎一样：
- 每隔几秒钟醒来一次
- 检查市场数据（就像检查游戏状态）
- 根据你编写的"策略代码"决定是否采取行动（买/卖）
- 记录所有操作到数据库
- 通过API/Telegram等方式报告状态

### 核心概念翻译（去金融化）

- **Trade（交易）** = 一个"会话"，从买入到卖出
- **Strategy（策略）** = 你的"决策算法"
- **Backtesting（回测）** = 用历史数据测试你的算法
- **Hyperopt（超参数优化）** = 自动调参，找最优配置
- **Exchange（交易所）** = 外部API服务商

## 三、主循环核心代码解析

### 🔄 主循环流程（在 `freqtradebot.py` 中）

**用程序员的话翻译这个循环：**

```python
# 伪代码版本
while bot_is_running:
    # 1. 同步数据（类似缓存刷新）
    reload_market_info()
    fetch_open_trades_from_db()
    
    # 2. 获取最新K线数据（HTTP请求）
    download_latest_candles()
    
    # 3. 运行你的策略代码（计算指标+判断信号）
    strategy.analyze(all_pairs)  # 这里调用你写的3个方法
    
    # 4. 加锁（防止并发问题）
    with thread_lock:
        # 先处理卖出（优先清仓）
        for trade in open_trades:
            if should_exit(trade):
                place_sell_order(trade)
        
        # 再处理买入
        if has_free_slots():
            for pair in whitelist:
                if should_enter(pair):
                    place_buy_order(pair)
    
    # 5. 提交数据库事务
    db.commit()
    
    # 6. 发送通知（Telegram/Webhook）
    send_notifications()
    
    # 7. 睡眠（节流）
    sleep(5)  # 默认5秒
```

### 实际代码流程

```python
def process(self) -> None:
    """
    主处理循环：查询持仓并处理，或创建新交易
    """
    # 1. 检查市场是否需要重载
    self.exchange.reload_markets()
    
    # 2. 更新未分配手续费的交易
    self.update_trades_without_assigned_fees()
    
    # 3. 从数据库查询开仓交易
    trades: list[Trade] = Trade.get_open_trades()
    
    # 4. 刷新活跃交易对白名单
    self.active_pair_whitelist = self._refresh_active_whitelist(trades)
    
    # 5. 刷新K线数据（下载最新数据）
    self.dataprovider.refresh(
        self.pairlists.create_pair_list(self.active_pair_whitelist),
        self.strategy.gather_informative_pairs(),
    )
    
    # 6. 调用策略的循环开始钩子
    strategy_safe_wrapper(self.strategy.bot_loop_start, supress_error=True)(
        current_time=datetime.now(UTC)
    )
    
    # 7. 执行策略分析（计算指标和信号）
    with self._measure_execution:
        self.strategy.analyze(self.active_pair_whitelist)
    
    # 8. 加锁处理订单管理
    with self._exit_lock:
        self.manage_open_orders()
    
    # 9. 加锁处理平仓
    with self._exit_lock:
        trades = Trade.get_open_trades()
        self.exit_positions(trades)
        Trade.commit()
    
    # 10. 处理仓位调整（如果启用）
    if self.strategy.position_adjustment_enable:
        with self._exit_lock:
            self.process_open_trade_positions()
    
    # 11. 寻找开仓机会
    if self.state == State.RUNNING and self.get_free_open_trades():
        self.enter_positions()
    
    # 12. 运行计划任务
    self._schedule.run_pending()
    Trade.commit()
    
    # 13. 处理RPC消息队列
    self.rpc.process_msg_queue(self.dataprovider._msg_queue)
    
    # 14. 记录处理时间
    self.last_process = datetime.now(UTC)
```

## 五、关键常量与配置

### 数据结构

标准K线数据（OHLCV）包含以下字段：
- **date**: 时间戳
- **open**: 开盘价
- **high**: 最高价
- **low**: 最低价
- **close**: 收盘价
- **volume**: 成交量

### 交易模式

- **现货交易（Spot）**: 直接买卖币种
- **杠杆交易（Margin）**: 借贷交易
- **期货交易（Futures）**: 合约交易

### 时间周期（Timeframe）

常用时间周期：
- `1m` - 1分钟
- `5m` - 5分钟
- `15m` - 15分钟
- `1h` - 1小时
- `4h` - 4小时
- `1d` - 1天
