# 第2章：核心模块详解

## 一、数据层模块

### 1.1 数据提供者（DataProvider）

DataProvider 是策略获取数据的主要接口，位于 `freqtrade/data/dataprovider.py`。

**主要功能：**
- 提供K线数据访问
- 提供订单簿数据
- 提供交易数据
- 缓存管理

**在策略中的使用：**

```python
from freqtrade.strategy import IStrategy

class MyStrategy(IStrategy):
    def populate_indicators(self, dataframe, metadata):
        # 获取当前交易对的K线数据（已在dataframe中）
        
        # 获取其他时间周期的数据
        if self.dp:
            # 获取1小时数据
            dataframe_1h = self.dp.get_pair_dataframe(
                pair=metadata['pair'],
                timeframe='1h'
            )
            
            # 获取订单簿数据
            if self.dp.runmode.value in ('live', 'dry_run'):
                orderbook = self.dp.orderbook(metadata['pair'], 1)
                dataframe['best_bid'] = orderbook['bids'][0][0]
                dataframe['best_ask'] = orderbook['asks'][0][0]
        
        return dataframe
```

### 1.2 历史数据管理

**数据下载：**

```bash
# 下载指定交易对的历史数据
freqtrade download-data \
    --exchange binance \
    --pairs BTC/USDT ETH/USDT \
    --timeframe 5m \
    --days 30

# 下载所有白名单交易对
freqtrade download-data \
    --config config.json \
    --timeframe 5m 1h \
    --days 365
```

**数据格式：**

Freqtrade 支持多种数据格式：
- `json` - JSON格式（默认）
- `jsongz` - 压缩JSON（节省空间）
- `feather` - Feather格式（快速）
- `parquet` - Parquet格式（推荐，最高效）

配置数据格式：

```json
{
    "dataformat_ohlcv": "parquet",
    "dataformat_trades": "parquet"
}
```

## 二、策略层模块

### 2.1 策略接口（IStrategy）

策略基类定义在 `freqtrade/strategy/interface.py`。

**必须实现的方法：**

```python
from pandas import DataFrame
from freqtrade.strategy import IStrategy
import talib.abstract as ta

class CustomStrategy(IStrategy):
    # ===== 配置参数 =====
    
    # 策略接口版本
    INTERFACE_VERSION = 3
    
    # 时间周期
    timeframe = '5m'
    
    # 止损比例
    stoploss = -0.10
    
    # 盈利目标
    minimal_roi = {
        "0": 0.10,    # 任何时候盈利10%就卖
        "30": 0.05,   # 30分钟后盈利5%就卖
        "60": 0.02    # 60分钟后盈利2%就卖
    }
    
    # 启动需要的K线数量
    startup_candle_count = 200
    
    # 是否支持做空
    can_short = False
    
    # ===== 必须实现的方法 =====
    
    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        """
        计算技术指标
        
        参数:
            dataframe: K线数据，包含 date, open, high, low, close, volume
            metadata: 元数据，包含 pair（交易对名称）
            
        返回:
            添加了指标列的 DataFrame
        """
        # 计算指标
        dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
        dataframe['ema_fast'] = ta.EMA(dataframe, timeperiod=12)
        dataframe['ema_slow'] = ta.EMA(dataframe, timeperiod=26)
        
        return dataframe
    
    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        """
        生成买入信号
        
        在满足条件的行上设置 dataframe['enter_long'] = 1
        """
        dataframe.loc[
            (
                # 条件1：RSI低于30（超卖）
                (dataframe['rsi'] < 30) &
                # 条件2：快线上穿慢线
                (dataframe['ema_fast'] > dataframe['ema_slow']) &
                # 条件3：有成交量
                (dataframe['volume'] > 0)
            ),
            'enter_long'
        ] = 1
        
        return dataframe
    
    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        """
        生成卖出信号
        
        在满足条件的行上设置 dataframe['exit_long'] = 1
        """
        dataframe.loc[
            (
                # 条件：RSI高于70（超买）
                (dataframe['rsi'] > 70)
            ),
            'exit_long'
        ] = 1
        
        return dataframe
```

### 2.2 可选的高级方法

```python
class AdvancedStrategy(IStrategy):
    
    def bot_loop_start(self, current_time: datetime, **kwargs) -> None:
        """
        每个循环开始时调用（每5秒一次）
        可用于清理缓存、更新全局状态等
        """
        pass
    
    def custom_stoploss(self, pair: str, trade: Trade, current_time: datetime,
                       current_rate: float, current_profit: float, **kwargs) -> float:
        """
        自定义止损逻辑
        
        返回值：止损价格相对于当前价格的比例
        返回 -0.05 表示当前价格下跌5%时止损
        返回 -1 表示不修改止损
        """
        # 盈利后设置保本止损
        if current_profit > 0.05:
            return 0.01  # 盈利5%后，设置止盈1%
        
        return -1  # 不修改
    
    def custom_exit(self, pair: str, trade: Trade, current_time: datetime,
                   current_rate: float, current_profit: float, **kwargs) -> str | None:
        """
        自定义退出逻辑
        
        返回值：退出原因字符串，或 None 表示不退出
        """
        # 持仓超过24小时且微盈利就退出
        if (current_time - trade.open_date_utc).total_seconds() > 86400:
            if current_profit > 0.01:
                return 'timeout_with_profit'
        
        return None
    
    def custom_stake_amount(self, pair: str, current_time: datetime,
                          current_rate: float, proposed_stake: float,
                          min_stake: float | None, max_stake: float,
                          leverage: float, entry_tag: str | None,
                          side: str, **kwargs) -> float:
        """
        自定义每笔交易的金额
        
        返回值：本次交易使用的金额
        """
        # 根据波动率调整仓位
        # 波动率大时减小仓位
        return proposed_stake
    
    def confirm_trade_entry(self, pair: str, order_type: str, amount: float,
                          rate: float, time_in_force: str, current_time: datetime,
                          entry_tag: str | None, side: str, **kwargs) -> bool:
        """
        交易确认钩子
        
        返回 True 允许交易，False 拒绝
        """
        # 可以添加额外的过滤条件
        return True
    
    def confirm_trade_exit(self, pair: str, trade: Trade, order_type: str,
                         amount: float, rate: float, time_in_force: str,
                         exit_reason: str, current_time: datetime, **kwargs) -> bool:
        """
        退出确认钩子
        """
        return True
```

## 四、持久化层（数据库）

### 4.1 Trade 模型

Trade 模型代表一笔完整的交易，定义在 `freqtrade/persistence/trade_model.py`。

**主要字段：**

```python
class Trade:
    id: int                    # 交易ID
    pair: str                  # 交易对，如 'BTC/USDT'
    is_open: bool              # 是否开仓中
    
    # 开仓信息
    open_rate: float           # 开仓价格
    open_date: datetime        # 开仓时间
    stake_amount: float        # 投入金额
    amount: float              # 买入数量
    
    # 平仓信息
    close_rate: float          # 平仓价格
    close_date: datetime       # 平仓时间
    close_profit: float        # 盈利比例
    close_profit_abs: float    # 绝对盈利
    
    # 止损信息
    stop_loss: float           # 止损价格
    stop_loss_pct: float       # 止损比例
    initial_stop_loss: float   # 初始止损价格
    
    # 其他信息
    exit_reason: str           # 退出原因
    enter_tag: str             # 进场标签
    fee_open: float            # 开仓手续费
    fee_close: float           # 平仓手续费
    
    # 关联订单
    orders: list[Order]        # 该交易的所有订单
```

## 五、插件系统

### 5.1 交易对列表管理器（PairList）

控制哪些交易对参与交易。

**内置 PairList 插件：**

1. **StaticPairList** - 静态列表
```json
{
    "pairlists": [
        {"method": "StaticPairList"}
    ],
    "exchange": {
        "pair_whitelist": ["BTC/USDT", "ETH/USDT"]
    }
}
```

2. **VolumePairList** - 按成交量排序
```json
{
    "pairlists": [
        {
            "method": "VolumePairList",
            "number_assets": 20,        // 保留前20个
            "sort_key": "quoteVolume",  // 按报价货币成交量排序
            "min_value": 0,
            "refresh_period": 1800      // 30分钟刷新一次
        }
    ]
}
```

3. **AgeFilter** - 过滤新上市的币
```json
{
    "pairlists": [
        {"method": "VolumePairList", "number_assets": 50},
        {
            "method": "AgeFilter",
            "min_days_listed": 10  // 至少上市10天
        }
    ]
}
```

4. **PriceFilter** - 价格过滤
```json
{
    "pairlists": [
        {"method": "VolumePairList", "number_assets": 50},
        {
            "method": "PriceFilter",
            "low_price_ratio": 0.01,   // 过滤价格太低的
            "min_price": 0.00000100    // 最低价格
        }
    ]
}
```

5. **SpreadFilter** - 价差过滤
```json
{
    "pairlists": [
        {"method": "VolumePairList", "number_assets": 50},
        {
            "method": "SpreadFilter",
            "max_spread_ratio": 0.005  // 买卖价差不超过0.5%
        }
    ]
}
```

### 5.2 保护机制（Protections）

防止在不利市场条件下继续交易。

```python
class MyStrategy(IStrategy):
    protections = [
        {
            "method": "StoplossGuard",
            "lookback_period_candles": 60,  # 查看60根K线
            "trade_limit": 4,               # 如果4笔交易
            "stop_duration_candles": 20,    # 触发止损，暂停20根K线
            "required_profit": 0.0          # 只算亏损交易
        },
        {
            "method": "CooldownPeriod",
            "stop_duration_candles": 5      # 卖出后冷却5根K线
        },
        {
            "method": "MaxDrawdown",
            "lookback_period_candles": 200,
            "trade_limit": 20,
            "stop_duration_candles": 10,
            "max_allowed_drawdown": 0.2     # 最大回撤20%
        }
    ]
```

## 六、解析器（Resolvers）

Resolvers 负责动态加载策略、交易所、超参数优化等模块。

### 6.1 策略解析器

```python
from freqtrade.resolvers import StrategyResolver

# 从配置加载策略
strategy = StrategyResolver.load_strategy(config)

# 动态加载策略
strategy = StrategyResolver.load_strategy({
    'strategy': 'MyStrategy',
    'strategy_path': '/path/to/strategies'
})
```

### 6.2 自定义策略路径

```json
{
    "strategy": "MyStrategy",
    "strategy_path": "user_data/strategies",
    "user_data_dir": "user_data"
}
```

## 本章小结

本章详细介绍了 Freqtrade 的核心模块：

1. **数据层**：DataProvider 提供数据访问，支持多种数据格式
2. **策略层**：IStrategy 接口定义策略结构，提供丰富的钩子方法
3. **交易所层**：统一的交易所接口，支持30+交易所
4. **持久化层**：SQLAlchemy ORM管理交易和订单数据
5. **插件系统**：PairList 和 Protections 提供灵活的扩展能力
6. **解析器**：动态加载各种模块
